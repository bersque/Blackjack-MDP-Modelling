# Blackjack-MDP-Modelling

This study aims to find an optimal strategy for playing blackjack. We model the game as a Markov Decision Process, interpreting states as triples representing the player’s hand value, the dealer's visible card, and the presence of an ace.
Card draws without replacement follow a hypergeometric structure, but are approximated as independent under infinite deck assumption. Since blackjack is usually played with 6-8 decks of 52 cards, this estimation doesn’t yield a notable error while significantly simplifying the transition model.

In each non-absorbing state of the game, we have two actions available: drawing or standing. After busting or standing, terminal rewards are calculated based on probabilities of game outcomes (win, loss or draw). Rewards are defined as +1 for win, 0 for draw, and −1 for loss. The Value Iteration algorithm solves Bellman equations, iteratively updating state utilities until the value changes drop below the assumed tolerance of error. An important parameter of the Bellman equations is discounting factor. It specifies the preference of algorithm for long-term rewards. In our model it’s set to as much as 0.999, since the long-term result is what primarily matters. The algorithm produces a policy that maximizes expected value of winning. The resulting strategy specifies the best action for each state. The model achieves 98.5% agreement with standard basic strategy charts. Discrepancies stem from simplifying assumptions, including the infinite deck and restricting the possible actions to only two. Nevertheless, this work demonstrates how Markov Decision Processes can be applied to stochastic decision-making problems with partial information.
